# Warrior Duel – Simple Text-Based Battle Game

A fun, turn-based fighting game written in pure Python using only the terminal.  
Fight against a warrior enemy — attack, regenerate health, and try to survive!

## Features

- Colorful terminal interface (thanks to colorama)
- Player vs AI enemy with random warrior behavior
- Health regeneration mechanic
- Win / lose conditions
- ASCII art title screen

## Requirements

- Python 3.6+
- colorama (`pip install colorama`)

## How to Play

1. Clone or download this repository
2. Open a terminal / command prompt
3. Navigate to the folder containing `idk.py`
4. Install dependencies (if not already installed):
